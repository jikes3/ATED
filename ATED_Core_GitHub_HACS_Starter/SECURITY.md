# Bezpečnost

Bezpečnostní chyby nezveřejňujte jako běžný issue. Do doby, než bude nastaven
soukromý bezpečnostní kontakt GitHubu, neposílejte diagnostiku obsahující hesla,
API klíče, přesnou adresu ani jiné citlivé údaje.

ATED Core 0.1.x je vývojová verze a nic neřídí. Přesto před aktualizací vždy
vytvořte zálohu Home Assistantu.
