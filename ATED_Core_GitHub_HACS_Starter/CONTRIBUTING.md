# Přispívání

1. Vytvořte větev z `main`.
2. Proveďte změny.
3. Zvyšte verzi pouze při přípravě vydání.
4. Ověřte syntaxi: `python -m compileall custom_components/ated_core`.
5. Otevřete pull request a vyčkejte na HACS, Hassfest a syntax kontrolu.

Historická data jsou append-only. Změna formátu musí zvýšit `SCHEMA_VERSION`
a doplnit migrační postup.
