# OpenHEMS Core 0.5.0

Home Assistant add-on pro lokální správu energie a vody.

## Novinky

- průvodce prvním spuštěním,
- automatické doporučení entit,
- Device Registry editor,
- dashboard s automatickým obnovováním,
- Ingress kompatibilní Swagger API.

Tato verze je pouze monitorovací a konfigurační. `dry_run` je ve výchozím stavu zapnutý a žádné zařízení se nespíná.
