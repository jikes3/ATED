# Changelog

## 0.5.0

- Průvodce prvním spuštěním s automatickým vyhledáním známých zařízení.
- Uložení doporučeného mapování do Device Registry.
- Grafický editor existujících mapování entit.
- Živý dashboard s automatickou aktualizací po 10 sekundách.
- Nové API `/api/dashboard` a `/api/discovery/apply`.
- Rozšířená detekce pro dešťovou nádrž, GoodWe, Wattrouter, bazénové TČ a počasí.
- Zachován bezpečný režim `dry_run`; verze 0.5.0 nic fyzicky nespíná.
